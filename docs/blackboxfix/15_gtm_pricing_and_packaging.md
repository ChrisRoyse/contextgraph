# Go-To-Market, Pricing, And Packaging

## Category

Position BlackBoxFix as Verified AgentOps:

- not just LLM observability;
- not just evals;
- not just policy gateway;
- not just audit logs.

The category claim is operational proof for AI agent actions.

## Initial Wedge

Start with DevOps/SecOps agent governance:

- coding agents;
- dependency remediation agents;
- CI repair agents;
- cloud change agents;
- vulnerability triage agents.

This wedge is concrete, budgeted, and verifiable.

## Buyer Personas

AI platform lead:

- wants reusable controls for many agent teams;
- cares about SDK, APIs, eval exports, model-provider neutrality.

CISO/security architect:

- cares about authorization, audit, incident response, SIEM, data controls.

Engineering leader:

- cares about shipping agents without breaking production.

Agent vendor:

- cares about enterprise trust, embedded SDK, customer proof.

## Offer

30-day pilot:

- one workflow;
- one agent runtime;
- first connector set;
- evidence dashboard;
- training/eval export;
- security review packet.

Pilot success metric:

- at least 20 real agent actions recorded;
- 100 percent mutating actions verified or blocked;
- at least one failed/blocked episode converted into an eval;
- buyer can replay a run and inspect source-of-truth evidence.

## Pricing Hypotheses

Developer:

- free or low-cost local recorder;
- JSONL exporter;
- local Git/file verifiers.

Team:

- per active agent or per verified run volume;
- shared dashboard;
- GitHub/CI/ticket integrations.

Enterprise:

- annual platform fee;
- usage tier for verified tool calls;
- private deployment premium;
- retention premium;
- custom connector package;
- compliance/audit export package.

Vendor/OEM:

- SDK license;
- per end-customer deployment;
- white-label enterprise controls.

## Metrics That Sell

- percentage of agent actions verified;
- number of blocked unsafe actions;
- mean time to root cause;
- evals generated from real failures;
- reduction in manual audit work;
- number of workflows allowed to move from supervised to bounded-autonomous.

## Sales Proof

The demo should show:

1. Agent performs useful operational work.
2. BlackBoxFix records the action.
3. Source-of-truth readback proves success.
4. A controlled failure produces a typed incident.
5. The failure becomes an eval/training row.

## Expansion Paths

- add more connectors;
- move from observe-only to governed mode;
- expand from DevOps to data operations;
- expand from one agent team to enterprise platform;
- sell training/eval corpus export to model improvement teams.
