How To Explain The Value

The buyer story

Gemma can decide to use a tool. BlackBoxFix proves what happened after that tool touched real state. It records the intent, the expected durable delta, the actual readback, the verifier result, and the incident if reality does not match expectation.

The technical proof

The proof is not the model response. The proof is the separate readback from SQLite, RocksDB, file hashes, command exits, artifact registry hashes, replay exports, and FSV certification artifacts.

Best positioning line: Gemma takes the action. BlackBoxFix proves whether the action actually persisted correctly.
