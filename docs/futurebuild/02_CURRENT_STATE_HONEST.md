## 5. What the `tasks/swebench-lite/*.json` corpus is for

300 SWE-bench Lite Python task manifests. They are NOT for the inner LLM (which doesn't exist). They are:

- **The Phase 0 mutation generator's input** — each task's known-good fix is mutated 8 ways to produce the corpus.
- **The Phase 8 holdout split's input** — train/calibration/holdout (240/30/30) under InstanceAtomic split.
- **The reality-capture corpus seed** — Claude Code attempts these tasks one-at-a-time; every Edit becomes a panel; every test outcome becomes an oracle label.

The 300 manifests live on. They feed the data flywheel, not the dead inner-loop.

## 6. Verifiable bottom line

If you `cargo build --release --workspace` from a fresh clone of `ccreality-cutover` branch right now:

- **Builds.** Workspace compiles. ME-JEPA crates compile.
- **Tests.** `cargo test --workspace` passes (~6.5k+ tests on the consolidated tree).
- **MCP starts.** `cargo run --release -p context-graph-mcp` boots, exposes 24 ME-JEPA tools. Production daemon roots must point at aiwonder `/zfs/archive/contextgraph/...` per #363; older `--d-root /mnt/d/contextgraph` invocations are local-only unless an issue explicitly scopes them that way.
- **`mejepa_verify` answers.** Calling the tool with a synthetic patch returns a `Verdict` (likely `OutOfDistribution` because no production training has run yet — that's expected and correct).
- **`mejepa_predict_latest` answers.** Returns an empty prediction list for an unknown/no-shift session, or the real persisted prediction rows if shifts/predictions have been observed.

What does NOT happen out of the box:

- Fresh-host, operator-verified first-time installation/enablement is not yet burned in, even though the injection hook, shift subscriber, scheduler entrypoint, and systemd template ship.
- The 300×8 Python corpus is present and the Phase A-E substrate is code/FSV-shipped, but production training/calibration/holdout cadence has not yet converged to the human-review-replacement gate.
- The ship gate ≥ 0.95 is not actually met: the latest verified ship-gate FSV reported final agreement `0.866667` against `0.95`. That is a Phase G model-quality convergence fact, not evidence that Phase A-E implementation is missing.

The futurebuild plan now moves from Phase A-F/H implementation closure into Phase G convergence, *without* rebuilding any of the Phase 0–8 architecture.
