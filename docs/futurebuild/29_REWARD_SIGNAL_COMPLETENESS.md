# 29 — Reward-Signal Completeness Audit (Maximum Capture from Durable Reality)

> **Authority.** This document is the canonical enumeration of every reward signal ME-JEPA-Code should be capturing from durable reality. It is the operationalization of LeCun's pillar #10 (transcript 2026-05-17: *"This system can derive reward signals from durable reality. ... You need to capture all the reward signals possible."*) and the operator-directed completeness mandate.
>
> **Companion EPIC:** [GitHub issue #315](https://github.com/ChrisRoyse/contextgraph/issues/315).

## §1 — Why this audit exists

The substrate generated by the prod-par6perf forward-cache run (391 shards × 1024 chunks × 12 embedders ≈ 4.9 M packed records) is the **primary** reward-signal source for ME-JEPA training. But there are many MORE reward signals derivable from durable reality that the system should be persisting + leveraging. This audit:

1. Enumerates every reward signal across 8 tiers.
2. Marks which signals are captured today vs pending.
3. Maps each pending signal to its TASK-RWD-NNN sub-task.
4. Defines the completeness acceptance gate.

Without explicit completeness tracking, the system silently leaves signal on the table — and silent gaps in reward density are the dominant failure mode for JEPA-class training.

## §6 — How to use this doc

1. **Before claiming a TASK-RWD-NNN issue**, read this doc top-to-bottom to understand which tier the signal belongs to and which other signals it interacts with.
2. **When implementing a new instrument**, register it in §2 (this doc), [`05_EMBEDDER_SIGNAL_MAP.md`](05_EMBEDDER_SIGNAL_MAP.md), [`03_ARCHITECTURE_BLUEPRINT.md`](03_ARCHITECTURE_BLUEPRINT.md), and [`04_DDA_TCT_CODE_ENRICHMENT.md`](04_DDA_TCT_CODE_ENRICHMENT.md). The instrument is part of the frozen target panel by construction; its computation must be deterministic and have zero trainable parameters.
3. **When adding a new reward signal that wasn't anticipated** (e.g., from an operator-directed expansion), file it as a new TASK-RWD-NNN sub-task under #315 + add it to the §2 tier table.
4. **At the per-cell stratified evaluation step** (Phase G ship gate), verify that every cell's training data spans tiers 1-7 (tier 8 is audit-only, doesn't enter training loss). Cells missing tier coverage are flagged for completeness backfill before the per-cell correlation ≥ 0.95 check.
