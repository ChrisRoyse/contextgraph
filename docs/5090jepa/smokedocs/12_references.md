- Use public taxonomy sources only if the exact downloaded artifact hash and
  license are recorded in `data_manifest.json`.
- Use public career trajectory datasets only after confirming license,
  provenance, and privacy posture.
- Cite JEPA/VICReg sources for architecture framing, not for claims that this
  system achieves their scale or benchmark results.
