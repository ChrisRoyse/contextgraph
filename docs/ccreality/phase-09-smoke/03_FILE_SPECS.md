# Phase 9 — File Specifications

## `scripts/cc/tests/smoke.sh`

The smoke script is the deterministic Phase 9 source of truth. It must be executable, fail closed with `set -euo pipefail`, and print `Smoke pass.` only after all physical readbacks pass.

Required behavior:

- Build `reality-loop`, `context-graph`, and `context-graph-mcp`.
- Run `reality-loop smoke` and read the returned `source_of_truth` files.
- Call MCP over JSON-RPC stdio for `tools/list`, `reality_run_smoke`, analyze tools, harness tools, optimizer tools, and drift comparison.
- Verify Claude Code sees the `cgreality` MCP server and can invoke `reality_latest_root`.
- Invoke hook scripts with real JSON stdin and inspect hook stdout, pre-edit state files, and hook event logs.
- Initialize a real BlackBox SQLite ledger, record an `agent_run`, record optimizer decision/recommendation tool calls, and inspect `ledger_records`.
- Use the governed command allowlist; the command smoke uses `git status --short`.
- Simulate drift on `scripts/cc/tests/hooks/fixtures/post_tool_use_target.txt`, then restore the tracked fixture byte-for-byte.
- Deny `.env` by checking both `.claude/settings.json` and PreToolUse hook output, while proving `.env` did not change.
- Reject malformed and over-limit recommendations, then prove ledger rows, recommendation files, and shift logs did not mutate.
- Print before/after state for at least three edge cases.
- Generate `docs/ccreality/SMOKE_RESULTS_<date>.md` and `/tmp/cgreality-smoke-<stamp>/smoke-report.json`.

## `docs/ccreality/SMOKE_RESULTS_<date>.md`

Generated by `scripts/cc/tests/smoke.sh`. It records:

- Run stamp, session id, smoke root, log path, report JSON path, runtime root, and BlackBox ledger path.
- PASS rows for Layers 0 through 8.
- Edge-case before/after state.
- Source-of-truth files physically read during verification.
- SQLite ledger row counts.
