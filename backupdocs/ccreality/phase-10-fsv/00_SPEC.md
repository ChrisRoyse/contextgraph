# Phase 10 — Specification

## Objectives

1. Implement `scripts/cc/tests/fsv.sh` — the master FSV runner that invokes per-case scripts.
2. Implement per-case scripts under `scripts/cc/tests/fsv/cases/` for each of the 39 cases (A1–F3).
3. Run the full FSV; iterate until all A–E pass, F within tolerance.
4. Generate `docs/ccreality/FSV_RESULTS_<date>.md` summarizing per-case results.

## Scope

```
scripts/cc/tests/fsv.sh                       # master runner
scripts/cc/tests/fsv/cases/A1_*.sh           # 5 A cases
scripts/cc/tests/fsv/cases/B1_*.sh           # 6 B cases
scripts/cc/tests/fsv/cases/C1_*.sh           # 12 C cases
scripts/cc/tests/fsv/cases/D1_*.sh           # 10 D cases
scripts/cc/tests/fsv/cases/E1_*.sh           # 3 E cases
scripts/cc/tests/fsv/cases/F1_*.sh           # 3 F cases
docs/ccreality/FSV_RESULTS_<date>.md         # generated by master runner
```

Total: 1 master + 39 cases = 40 scripts, plus the results doc.

## Pass criteria

- All A1–A5 PASS.
- All B1–B6 PASS.
- All C1–C12 PASS.
- All D1–D10 PASS.
- All E1–E3 PASS.
- F1–F3 PASS or within documented tolerance (e.g., F1 cost within 30% of budget).

## Time budget

2–4 hours:
- Master runner + result-doc generator: 30 min.
- A cases (5): 30 min.
- B cases (6): 30 min.
- C cases (12): 60–90 min (most complex).
- D cases (10): 30 min (most reuse Phase 6 unit tests).
- E cases (3): 30 min (require live Claude Code sessions).
- F cases (3): 30 min.
- Iteration on failing cases: 0–60 min.

## What the cases prove (per [../18_FSV_PLAN.md](../18_FSV_PLAN.md))

| Category | Proves |
|----------|--------|
| A — Engine artifacts | The reality engine produces internally consistent artifacts |
| B — MCP analyze | Read tools return verbatim what the engine wrote |
| C — MCP alter + shift | Write tools follow the shift discipline; SHA mismatches fail; locks work |
| D — Hooks | Hooks emit correct JSON; deny enforcement is real |
| E — Drip + drift end-to-end | A full Claude Code session perceives reality and detects drift |
| F — Cost and limits | Bounded behavior under budget caps |
